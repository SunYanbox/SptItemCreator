## 模组配置

配置文件位置：`游戏根目录\SPT\user\mods\SptItemCreator\config.json`

### 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| ignoreTemplateFiles | bool | true | 忽略名称中带有"模板"或"Template"的文件与文件夹 |
| cacheInitialized | bool | false | 缓存是否已初始化。首次运行后自动设为 true，后续启动跳过统计计算 |
| alwaysUpdateCache | bool | false | 设为 true 时强制执行哈希检查并更新变化的缓存 |
| requiredItemIds | List\<string\> | null | 必需物品ID列表，启动时验证存在性和启用状态 |

### 示例配置

```json
{
    "ignoreTemplateFiles": true,
    "cacheInitialized": false,
    "alwaysUpdateCache": false,
    "requiredItemIds": []
}
```

### 配置项详解

#### ignoreTemplateFiles

控制是否忽略模板文件。当设为 `true` 时，模组会跳过名称中包含"模板"或"Template"的文件及其所在文件夹下的所有文件。

**使用场景**：
- 开发调试时使用模板文件作为参考，但不希望加载到游戏中
- 保持模板文件在 data 目录中作为示例

#### cacheInitialized

缓存初始化状态标志。模组首次运行完成统计数据收集后会自动将其设为 `true`。

**使用场景**：
- 首次启动时为 `false`，模组执行统计计算
- 后续启动时为 `true`，跳过统计计算，加快启动速度
- 若需重新统计，可手动改为 `false`

#### alwaysUpdateCache

强制更新缓存开关。设为 `true` 时，无论 `cacheInitialized` 状态如何，都会执行哈希检查并更新变化的缓存。

**使用场景**：
- SPT 数据库更新后需要重新构建缓存
- 物品数据发生大规模变更

#### requiredItemIds

必需物品ID列表。模组启动时会验证这些ID对应的物品是否存在且已启用。

**使用场景**：
- 你的模组依赖其他模组创建的物品
- 确保依赖物品已正确加载

**示例**：

```json
{
    "requiredItemIds": [
        "5448e8d04bdc2ddf718b4569",
        "5448ff904bdc2d6f028b456e"
    ]
}
```

当列表中的物品缺失或未启用时，模组会输出详细的错误日志：

```
[ERROR] 必需物品不存在: 5448e8d04bdc2ddf718b4569
[ERROR] 必需物品未启用: 5448ff904bdc2d6f028b456e
```
