**后缀名要求: `.sic`或`.sic.json`或`.sic.jsonc`**

模板文件命名规范: 带有`模板`或`Template`的数据文件名称

## JSONC 注释支持

数据文件支持带注释的 JSONC 格式，可使用以下注释语法：

```jsonc
{
    // 单行注释：物品唯一ID
    "id": "6900c8e93ea877662a000012",
    
    /* 
     * 多行注释：
     * 物品属性说明
     */
    "attributeInfo": {
        "weight": 0.3
    }
}
```

**注意**：字符串内的注释标记会被正确处理，不会误删。

## 类型机制说明

物品的属性由**实际赋值的 Info 字段**决定，模组会自动应用已提供的所有 Info 数据：

| 提供的 Info 字段 | 应用的属性 |
|------------------|-----------|
| `attributeInfo` | 物理属性（重量、尺寸、稀有度等） |
| `buffsInfo` | Buff 效果（食物/针剂的增益效果） |
| `drinkFoodInfo` | 食物/饮料属性（使用时间、能量恢复等） |
| `medicalInfo` | 医疗属性（耐久、回复速率、使用时间等） |
| `ammoInfo` | 弹药属性（伤害、穿甲、弹道等） |

**注意**：`baseInfo.type` 字段仅用于标识目的，不影响实际属性应用逻辑。可同时提供多个 Info 字段，模组会依次应用所有已赋值的属性。

## common类型数据文件

```json
{
    "enable": false, // 修改后, 确定要添加后再改为true
    "baseInfo": {
        "id": "6900c8e93ea877662a000012", // 必须有, 且唯一
        ......
    },
    "propertyOverride": { // 可缺省，提供最全面的属性覆盖功能
        ......
    },
    "attributeInfo": { // 可缺省，封装了物品常用的一些属性
        ......
    },
    "buffsInfo": { // 可缺省，封装了食物/针剂的效果注册
        ......
    }
}
```

通用物品类型，除了`baseInfo`,`attributeInfo`,`buffsInfo`外其他未封装的修改数据都要写入`propertyOverride`字段

注意，当`baseInfo`中没有提供`cloneId`时，新物品的所有属性都来自于`propertyOverride`字段

**注意: id必须提供; traderId不提供或提供有误时不会添加给商人; 其他属性都有默认值**

`propertyOverride`的数据类型为[TemplateItemProperties](../数据结构/SPT常用数据结构/新物品相关/TemplateItemProperties.md), 且优先级会低于其他封装过的字段(例如如果同时在`attributeInfo`和`propertyOverride`中赋值了`Weight`属性，模组会用`attributeInfo`的`Weight`属性覆盖`propertyOverride`的`Weight`属性)

## drinkOrFood类型数据文件

提供 `drinkFoodInfo` 字段，可以设置食物使用时间，食物耐久量(特指饮品)，恢复或扣除的能量值/水分

## medical类型数据文件

提供 `medicalInfo` 字段，提供了药品耐久/使用次数，生命回复速率，药品使用时间，药品效果生效类型，手术优先治疗部位等数据的封装

## ammo类型数据文件

提供 `ammoInfo` 字段，提供了弹药类型，初始速度，弹头质量，基础伤害值，穿甲能力，对护甲伤害，破片概率，跳弹概率，流血相关伤害值，曳光弹相关数据，后坐散步等数据的封装

## 不同类型支持的字段与示例

通用字段：**BaseInfo**(必须)、AttributeInfo、BuffsInfo、propertyOverride

| 提供的特殊字段 | 对应功能类型 |
| -------------- | ------------ |
| 无             | 通用物品     |
| drinkFoodInfo  | 食物/饮料    |
| medicalInfo    | 医疗物品     |
| ammoInfo       | 弹药         |

> **向后兼容**：旧版本数据文件中的 `$type` 字段仍可被正确读取，但不会输出到新文件中。建议移除 `$type` 字段，使用 Info 字段控制属性应用。
