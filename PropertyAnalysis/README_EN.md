## PropertyAnalysis

A Python project for analyzing cache data generated by mods

Install dependencies (not highly recommended):

```shell
conda activate <yourEnvName>
conda install --yes --file requirements.txt
```

Minimum dependencies (recommended to install these after creating a virtual environment; if errors occur, install missing ones and then please open an issue on Github):

- pyyaml
- matplotlib (will automatically install numpy, contourpy, etc. during installation)
- aiofiles (asynchronous loading of data files)
- flask (not required if API functionality is not used)

Run script (GUI):
```shell
python main.py
```

Run Flask server (only provides local network interface)
```shell
python app.py
```

## Script Functionality

Launches a GUI interface implemented with tkinter, which can collect data from cache files created during SptItemCreator runtime, provide various statistical data, and display all attribute names and assignments available for a category of items, facilitating item creation

![Bullet attribute example](images/img.png)

## Getting Started

1. Create a file named `config.yaml` in the same directory as main.py, and include at least the content of [Required Configuration](#required-configuration)
2. Open the window, menu bar: File -> Load Data from Folder
3. Select `Game Root Directory/SPT/user/mods/SptItemCreator/StatsCache`

## Required Configuration

Need to create a file named `config.yaml` in the current directory for configuration settings

```yaml
# Language setting: zh (Chinese), en (English)
Language: en

# Default values
StatsManagerSavePath: "data/StatsManager.plk"
CachePath: data/Cache.cache

# Debug values (place paths as list strings if empty; the last one is currently unused)
DataLoaderTestFilePaths:

DataLoaderTestFolder:

SptItemCreatorStatsCacheFolderPath: "Absolute path to SptItemCreator/StatsCache"
```
